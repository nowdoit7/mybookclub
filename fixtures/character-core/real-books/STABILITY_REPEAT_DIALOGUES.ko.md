# Character Core 안정성 반복 대사

이 문서는 `rbt-v2-stability-repeats` 실행의 오프라인 검토본이다. 외부 API와 앱 API를 호출하지 않았으며, 최신 r0의 질문·상태·허용 근거를 그대로 사용해 18개 고정 셀마다 독립적인 r1·r2 대사를 작성했다. 역사 인물 페르소나는 편집적 재구성이며, 대사는 직접 인용이나 허용 범위 밖의 사실 없이 1~3문장으로 제한했다.

- 전체 대사: 36개
- 반복 구성: 18개 기준 셀 × r1·r2
- 문장 수: 1문장 6개, 2문장 22개, 3문장 8개
- 생성기: `offline-core-v2-repeat-no-api`

- 작품 사실: 덕의 중용은 모든 사람에게 같은 산술적 중간값이 아니라 상황과 행위자에게 맞는 과도함과 모자람 사이의 적절함이다. 중용은 자동 결정 규칙이 아니며, 구체적 상황에서 무엇이 적절한지는 훈련된 판단이 필요하다. 자발성, 비자발성, 선택과 숙고의 구분은 행위자를 언제 칭찬하거나 비난할 수 있는지 판단하는 토대다. 실천적 지혜는 좋은 목표를 구체적 상황에서 실행 가능한 올바른 수단과 연결하는 능력이다.
- 독자 추론: 상대 설명의 출발점은 받아들인 뒤 기계적 규칙으로는 처리할 수 없는 상황 판단과 책임 조건을 반대 근거로 제시한다.
