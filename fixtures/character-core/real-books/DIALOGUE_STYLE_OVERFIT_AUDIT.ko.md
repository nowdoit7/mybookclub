# Character Core v2 대화 스타일·오버핏 감사

감사 시점: 2026-07-24  
대상: Character Core 기본 180개, legacy 비교군 45개, 반복 안정성 36개  
평가 단위: 9권 × 4캐릭터 × 5질문, 그중 3권은 출력 미열람 홀드아웃  
이전 v1 문서는 `round-v1/`에 보존되어 있다.

## 결론

Character Core v2는 **로컬 A/B 실험에 연결할 수 있는 수준으로 통과**했다.

- Character Core 기본 대사 블라인드 식별률은 91.1%다.
- 개발 세트 89.2%, 홀드아웃 95.0%로 홀드아웃 하락이 없다.
- 네 캐릭터 모두 사전 기준인 60%를 넘었고, 가장 약했던 마커스도 88.9%다.
- 근거성은 4.97/5, 희화화 위험은 1.34/5다.
- 보이는 대사의 내부 평가 용어는 0건이다.
- 261개 발화가 한 문장 수로 붕괴하지 않았고, 가장 큰 2문장 구간은 60.15%다.

다만 이것은 “캐릭터 문제가 완전히 해결됐다”는 뜻이 아니다. 정의·관용 독자는 기본 대사에서 100% 식별됐지만 반복 표본 식별률은 60%였고, 특정 판단 어휘가 강한 표면 단서가 될 위험이 있다. 또한 실제 앱의 긴 대화·사용자 정정·타깃 전환까지는 이번 단문 배터리가 검증하지 않는다. 따라서 **배포 기본값이 아니라 로컬 전용 실험**으로 진행한다.

## v1 대비 변화

| 항목 | v1 | v2 | 판단 |
|---|---:|---:|---|
| Character Core 전체 식별률 | 78.3% | 91.1% | 개선 |
| 마커스 식별률 | 55.6% | 88.9% | 실패선 해소 |
| 홀드아웃 식별률 | 80.0% | 95.0% | 개선, 하락 없음 |
| 내부 용어 노출 | 11/180 | 0/261 | 해소 |
| 모든 기본 대사가 2문장 | 180/180 | 108/180 | 붕괴 해소 |
| Core 상호작용형 질문·확인 | 사실상 0 | 21/72 | 목표 25~40% 충족 |
| 근거 결정 기록 | 없음 | 261/261 | 사실·해석 경계 추가 |

v1 이후 한 번의 규칙 개정과 한 번의 전체 재생성만 수행했다. v2 블라인드 결과를 본 뒤 대사를 고쳐 재채점하지 않았다. 마커스의 『이방인』 한 행에서 발견된 hard failure도 그대로 기록한다.

## 캐릭터별 감사

### 아이작 뉴턴

- 기본 식별률 84.4%, 반복 식별률 100%.
- 결과 → 작동 원리 → 빠진 조건 → 일반화 범위의 순서가 대체로 유지됐다.
- `조건` 계열과 `작동`이 자주 보인다. 이는 핵심 사고 절차이면서 동시에 표면 단서가 될 수 있다.
- 마커스와 혼동된 기본 대사는 2개뿐이지만, 무라사키로 읽힌 행이 4개 있어 인간관계 장면에서 기제보다 관계 변화가 앞서지 않는지 런타임 로그에서 확인해야 한다.

### 마커스

- 기본 식별률 88.9%, 반복 식별률 100%.
- v1의 가장 큰 실패였던 뉴턴과의 혼동이 크게 줄었다.
- 책임 귀속, 반대 증거, 판단 절차가 작동 원리·조건과 분리되어 읽혔다.
- `반대`, `책임`, `검토`가 반복된다. 법정 역할극은 줄었지만 이 어휘가 새 캐치프레이즈가 되지 않도록 한 세션 안에서 반복 예산을 둬야 한다.

### 무라사키 시키부

- 기본 식별률 91.1%, 반복 식별률 80%.
- 확인된 행동과 관계·발언권 변화가 내면 추정보다 먼저 나오는 규칙이 효과가 있었다.
- `행동`, `관계`, `자리` 계열이 반복된다. 근거가 행동이 아닌 과학·철학 책에서도 억지로 관계 서사로 바꾸지 않는지 실제 세션에서 본다.

### 정의·관용 독자

- 기본 식별률 100%, 반복 식별률 60%.
- 비용 배분, 동일 기준, 복구 가능성의 순서가 매우 강하게 구별됐다.
- 동시에 `같은`, `비용`, `기준`이 가장 강한 어휘 표지가 되었다. 높은 기본 식별률을 곧바로 안정된 인격으로 해석하면 안 된다.
- 현재 실제 앱 PersonaCard가 없으므로 런타임에 억지로 추가하지 않고 오프라인 대조군으로 남긴다.

## 책·질문 기능별 취약점

- 『오만과 편견』은 70.0%로 가장 낮았다. 네 캐릭터가 모두 판단 수정과 관계 비용을 다루면서 경계가 가까워졌다.
- 직접 반론은 80.6%로 질문 기능 중 가장 낮았다. 단호함이 강해질 때 캐릭터 고유의 판단 순서가 “반대합니다”라는 공통 표면으로 압축되기 쉽다.
- 반증 뒤 수정은 97.2%로 높지만 구어성은 4.08로 가장 낮다. `유지하겠습니다/고치겠습니다` 같은 보고서형 종결을 실제 앱에서 감시한다.
- 마커스의 `STR-Q2`는 폭력을 핵심 근거로 골랐지만 질문이 요구한 “그 근거만으로 말할 수 없는 한계”를 답하지 않아 `question_not_answered` hard failure가 1건 발생했다. 점수 맞춤 수정을 하지 않고 회귀 사례로 보존한다.

## Core 대 legacy 비교

동일한 45셀에서:

| 변형 | 식별률 | 구어성 | 근거성 | 주장 충실도 | 개성 | 희화화 위험 |
|---|---:|---:|---:|---:|---:|---:|
| Character Core v2 | 91.1% | 4.24 | 5.00 | 4.91 | 4.42 | 1.31 |
| Legacy PersonaCard | 84.4% | 4.24 | 4.87 | 4.93 | 4.16 | 1.27 |

Core는 식별성·근거성에서 개선됐지만 구어성은 같고, 희화화 위험도 legacy보다 유의하게 낮아졌다고 말할 수 없다. 즉 이번 개선의 근거는 “더 화려한 말투”가 아니라 **판단 순서와 근거 경계가 더 잘 구별됐다**는 데 있다.

## 로컬 실험 승인 조건

다음 경계를 지키는 경우에만 앱에 연결한다.

1. `?characterCore=1`과 loopback hostname이 함께 있을 때만 활성화한다.
2. Firebase/배포 서버 기본값은 비활성화하고, 조작된 요청도 서버에서 403으로 차단한다.
3. 한국어 세션의 기존 마커스·뉴턴·무라사키 카드에만 적용한다.
4. 스피커, 타깃, 단계, 질문 기능, 상태 선택은 계속 코드가 결정한다.
5. 독서 노트와 대사에 필요한 최소 Core 조각만 보내고 출처 URL·업적·전체 상태표는 보내지 않는다.
6. 실험 세션은 generation HTTP 요청 45회로 제한하고 UI·내보내기에 실험임을 표시한다.
7. 배포·push·merge는 사용자 승인 전까지 하지 않는다.

## 실제 사용자 테스트에서 볼 것

- 책이 바뀌어도 같은 핵심 단어를 반복하는가.
- 반론 시 상대의 정확한 주장에 답하는가, 공통적인 “반대합니다”로 축약되는가.
- 사용자의 정정이 들어오면 이후 모든 독자가 사실 경계를 갱신하는가.
- 무라사키의 행동·관계 추론이 근거 없는 마음 읽기로 넘어가지 않는가.
- 뉴턴과 마커스가 각각 기제와 책임을 실제로 다르게 다루는가.
- 지목된 상대와 화면 초상화·발화 타깃이 일치하는가.
- “의견 보태기” 뒤 중재자가 불필요하게 끼어들지 않고 사용자 입력으로 바로 이어지는가.

최종 판정은 **오프라인 전이 평가 통과, 로컬 실험 진행, 운영 적용 보류**다.
