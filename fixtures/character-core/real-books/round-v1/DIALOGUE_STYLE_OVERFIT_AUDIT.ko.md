# 실제 도서 Character Core 대화 스타일·오버핏 감사

작성일: 2026-07-24  
대상: Character Core 180개 발화와 공통 조건의 legacy 45개 발화  
범위: 문체 반복, 캐릭터 붕괴, 질문 응답성, 구어체 자연스러움, 표면 시그니처 의존, A/B 비교  
제외: 블라인드 정답표와 API 출력. 이 감사에서는 비블라인드 로그의 `personaId`만 사용했다.

## 한눈에 보는 결론

Character Core는 **문장 복사나 직업 말투 흉내 수준의 오버핏은 대체로 피했다.** 특히 legacy 마커스의 법정 역할극을 크게 줄였고, 책마다 구체적인 장면과 논점을 사용했다. 따라서 “책이 바뀌어도 완전히 같은 대사를 붙인다”는 수준의 실패는 아니다.

그러나 현재 180개 결과만으로 “사람처럼 개성 있게 대화한다”고 결론 내리기는 어렵다. 가장 큰 문제는 캐릭터 카드보다 **평가 질문의 동일한 5단 구조와 근거팩 중심 지시가 모든 캐릭터를 같은 두 문장짜리 근거 검토자로 만든다는 점**이다. 표면 문구는 달라도, `부분 동의 → 근거로 범위 제한`, `판단 유지 → 일부 철회`라는 답의 골격과 최종 입장이 자주 같다.

종합 판정은 다음과 같다.

| 항목 | 판정 | 요약 |
|---|---|---|
| 문장 그대로의 반복 | 낮음 | Character Core 전체에 완전히 같은 문장은 없고, 한 페르소나의 45개 발화 중 6개 이상에서 반복된 2~4어절 구문도 없었다. |
| 책을 바꿔도 같은 결론 | 중간 | 책 고유 사실은 사용하지만, 캐릭터마다 늘 같은 도덕·인식 프레임으로 회수하는 경향이 있다. |
| 캐릭터 간 같은 목소리 | 중간~높음 | 동일 질문에서 결론과 논증 순서가 수렴한다. 뉴턴과 마커스가 가장 자주 겹친다. |
| 표면 시그니처 의존 | 중간 | legacy 마커스의 법정어는 개선됐지만, 뉴턴의 `조건`, 무라사키의 `자리·관계`, 진의 `기준·책임`이 새 시그니처 단어로 굳을 조짐이 있다. |
| 구어체 자연스러움 | 높음 위험 | 180개가 모두 정확히 2문장이고 실제 물음표는 0개다. 대화보다 잘 정리된 미니 평론에 가깝다. |
| 질문 응답성 | 대체로 양호 | 완전히 질문을 빗나간 사례는 찾지 못했다. 다만 캐릭터 코어를 적용하려다 허용 근거 밖으로 해석을 보탠 사례가 있다. |
| A/B 개선 | 부분 성공 | Character Core는 caricature를 줄였지만, legacy와 같은 결론을 다른 단어로 말하는 경우가 많고 `근거팩` 같은 내부 용어가 새로 노출됐다. |

## 감사 방법과 정량 결과

- JSONL 4개 파일, 총 225개 발화를 직접 비교했다.
- 같은 캐릭터의 책 간 반복, 같은 질문에서 캐릭터 간 반복, 공통 45개 조건의 Character Core/legacy 쌍을 각각 비교했다.
- 공백과 문장부호를 제거한 문자 3-gram cosine은 의미 동일성을 완전히 측정하지 못하므로 **반복 후보를 찾는 보조 지표**로만 사용했다.
- 모든 수치는 `dialogue` 필드의 단순 문자열 출현 기준이다. 형태소 분석 수치가 아니다.

### 구조와 자연스러움

- Character Core 180/180개가 정확히 2문장이다.
- legacy 45/45개도 정확히 2문장이다.
- Character Core에서 물음표를 사용한 발화는 0/180개다.
- `first_impression`, `evidence_selection`, `respond_to_user`, `directed_rebuttal`, `revise_after_counterevidence` 모두 각 36개이며, 어느 유형에도 질문형 발화가 없다.
- Character Core 최종 문장이 `요` 계열로 끝난 것은 39/180개, `습니다/겠습니다` 계열로 끝난 것은 58/180개다. 어미 변화는 생겼지만 상호작용 형태는 모두 진술문이다.
- Character Core가 내부 평가 용어인 `근거팩`을 직접 말한 사례는 11/180개다. legacy에는 0/45개다.

### 반복과 유사도

- Character Core 180개와 legacy 45개를 합쳐 완전히 같은 문장은 없었다.
- Character Core에서 같은 캐릭터가 서로 다른 책에 한 답 가운데 문자 3-gram 유사도 최고치는 뉴턴 0.284, 마커스 0.150, 무라사키 0.094, 진 0.197이었다. 문장 복사 오버핏은 강하지 않다.
- 동일 질문에서 서로 다른 Character Core 캐릭터끼리의 평균은 0.130, 최고는 0.364였다. 평균은 낮지만, 아래의 수동 검토 사례처럼 **핵심 결론과 논증 순서가 사실상 같은 쌍**이 있다.
- 같은 캐릭터·책·질문의 Character Core/legacy 평균은 뉴턴 0.176, 마커스 0.135, 무라사키 0.129였다. 최고치는 각각 0.350, 0.336, 0.251이었다.

### 코어 단어 집중도

| 페르소나 | 자주 노출된 코어 단어 | 포함 발화 수 |
|---|---|---:|
| 뉴턴 | `조건` | 24/45 |
| 뉴턴 | `근거` | 14/45 |
| 마커스 | `근거` | 24/45 |
| 마커스 | `책임` | 17/45 |
| 마커스 | `주장` | 16/45 |
| 무라사키 시키부 | `관계` | 17/45 |
| 무라사키 시키부 | `자리` | 15/45 |
| 무라사키 시키부 | `마음` | 10/45 |
| 진 | `기준` | 18/45 |
| 진 | `책임` | 14/45 |
| 진 | `공정` | 10/45 |

이 수치만으로 오버핏이라고 단정할 수는 없다. 문제는 이 단어들이 책의 고유한 긴장을 여는 대신, **모든 책을 익숙한 캐릭터 표어로 회수하는 지름길**이 될 때다.

## 세부 발견

### [높음] 평가 질문이 답의 구조와 결론을 지나치게 결정한다

현재 9권 모두에 같은 다섯 역할이 같은 순서로 적용된다. 특히 Q3는 사용자의 해석에서 “맞는 부분과 과장된 부분”을 나누게 하고, Q5는 반대 근거를 받은 뒤 판단을 수정하게 한다. 이 설계는 사실 충실도는 검사하지만, 캐릭터가 스스로 무엇을 문제 삼는지보다 **요청받은 논증 형식을 얼마나 잘 재현하는지**를 더 강하게 측정한다.

가장 높은 캐릭터 간 문자 유사도 0.364가 나온 쌍은 다음과 같다.

- `rbt-v1:character_core:isaac-newton:atomic-habits-james-clear:ATO-Q3:r0`
  - “목표만 세워서는 변화가 지속되지 않는다는 뜻이라면 맞습니다. 그러나 목표도 방향을 주고 적절한 도전과 피드백이 동기를 돕는다고 했으니…”
- `rbt-v1:character_core:marcus:atomic-habits-james-clear:ATO-Q3:r0`
  - “목표만으로 지속적 변화가 생기지는 않는다는 요지는 맞습니다. 그래도 목표가 방향을 줄 수 있고 적절한 도전과 피드백이 동기를 돕는다고 했으니…”

두 답은 단어만 약간 다를 뿐, 인정하는 범위와 반박 근거와 결론이 같다. 이것은 두 캐릭터가 실패했다기보다 질문이 사실상 모범 답안을 지정한 결과다.

다른 대표 사례:

- `rbt-v1:character_core:isaac-newton:pride-and-prejudice-jane-austen:PNP-Q3:r0`
  - “첫 관찰에는 근거가 있었습니다. 그러나 … Wickham의 설명을 쉽게 받아들였고 … 처음부터 정확했다는 일반화는 유지하기 어렵습니다.”
- `rbt-v1:character_core:marcus:pride-and-prejudice-jane-austen:PNP-Q3:r0`
  - “거만한 태도를 정확히 보았지만 … Wickham의 설명을 … 쉽게 받아들였습니다. … 처음부터 정확했다는 주장은 수정해야 합니다.”

이 상태로는 책 holdout이 성공해도 질문 형식에 대한 overfit을 배제할 수 없다. 현재 holdout은 책만 새롭고, 대화 행위의 틀은 이미 노출된 상태다.

### [높음] 모든 결과가 두 문장짜리 미니 평론이며 실제 대화 행동이 없다

Character Core에는 질문 방식, 상태 변화, 양보, 수리 행동이 정의돼 있지만 출력은 180개 모두 정확히 두 개의 진술문이다. 캐릭터가 상대의 말을 되묻거나, 잠깐 망설이거나, 한 문장으로 강하게 끊거나, 구체적 장면을 다시 확인하는 리듬이 없다.

대표적으로 다음 발화들은 정확하지만 실제 독서 모임에서 입으로 말하기보다는 평가 보고서에 가깝다.

- `rbt-v1:character_core:isaac-newton:cosmos-carl-sagan:COS-Q5:r0`
  - “시간과 규모를 잇는 서사가 탐구를 돕는다는 판단은 유지하겠습니다. 다만 … 각 설명의 확실성까지 높다고 본 부분은 철회하고…”
- `rbt-v1:character_core:marcus:cosmos-carl-sagan:COS-Q5:r0`
  - “우주 진화를 잇는 서사가 이해를 돕는다는 평가는 남기겠습니다. 하지만 … 각 주장의 입증 수준을 따로 기록하겠습니다.”
- `rbt-v1:character_core:justice-tolerance-reader:nicomachean-ethics-aristotle:NIC-Q5:r0`
  - “공동체에서 정의를 실천하는 일이 중요하다는 판단은 그대로 두겠습니다. 다만 … 닫았던 결론은 고치고…”

Q5의 `판단/평가 → 유지/철회/수정` 형식은 올바른 revision을 확인하기에는 좋지만, 실제 서비스 대사로 그대로 가져오면 캐릭터 모두가 자기 의견을 행정적으로 정정하는 사람처럼 들린다.

반대로 아래 발화는 같은 근거 중심 답이어도 상대에게 말하는 느낌이 더 살아 있다.

- `rbt-v1:character_core:murasaki-shikibu:nineteen-eighty-four-george-orwell:N84-Q4:r0`
  - “아니요, 두 사람이 서로를 배신한 뒤 관계가 이전으로 돌아오지 않았다는 점을 빼면 안 됩니다.”
- `rbt-v1:character_core:murasaki-shikibu:atomic-habits-james-clear:ATO-Q4:r0`
  - “의지가 약하다는 한마디로 사람을 줄여 부르지 마세요.”
- `rbt-v1:character_core:justice-tolerance-reader:one-hundred-years-of-solitude-gabriel-garcia-marquez:OHS-Q1:r0`
  - “새로운 것을 좇는 선택 자체는 받아들일 수 있어요. 하지만 그 선택의 비용을 우르술라와 아이들이 … 감당했다면…”

이 예외의 리듬을 늘리고, 모든 답을 같은 두 문장으로 맞추는 생성 규칙은 풀어야 한다.

### [높음] 근거 관리용 내부 언어가 캐릭터의 입으로 노출된다

사실 검증 장치는 필요하지만, 등장인물이 사용자에게 `근거팩`, `사용자 발제`, `검증된 작품 사실`이라고 말하면 독서 모임의 환상이 깨지고 “이 캐릭터는 책을 읽지 않고 요약 자료만 받았다”는 느낌을 강화한다.

특히 『이방인』 Q3에서 네 캐릭터가 모두 거의 같은 provenance 안내자가 된다.

- `rbt-v1:character_core:isaac-newton:the-stranger-albert-camus:STR-Q3:r0`
  - “David가 제기한 다섯 발과 동기 부재는 사용자 발제로 확인될 뿐, 이 근거팩에서 검증된 작품 사실은…”
- `rbt-v1:character_core:marcus:the-stranger-albert-camus:STR-Q3:r0`
  - “근거팩이 확인하는 것은 해변의 살인이므로…”
- `rbt-v1:character_core:murasaki-shikibu:the-stranger-albert-camus:STR-Q3:r0`
  - “근거팩은 해변의 살인만 확인하므로…”
- `rbt-v1:character_core:justice-tolerance-reader:the-stranger-albert-camus:STR-Q3:r0`
  - “근거팩은 해변의 살인을 확인하지만 횟수와 동기는 검증하지 않으니…”

사실 관리 결과는 유지하되, 서비스 대사에서는 “제가 확인한 장면만 놓고 보면”, “그 숫자는 지금 단정하지 않을게요”처럼 자연스러운 범위 제한으로 렌더링해야 한다. 더 좋은 방법은 provenance 판단을 내부 필드로 남기고 대사에서 관련 전문어를 숨기는 것이다.

### [중간~높음] 공통의 evidence-first 하우스 보이스가 캐릭터 코어보다 강하다

뉴턴과 마커스는 특히 `근거·주장·확인·조건`을 공유해 자주 가까워진다. 뉴턴은 원인과 일반화 범위를, 마커스는 책임 귀속과 반증을 보도록 설계됐지만, 현재 질문이 대부분 “근거를 골라 정확한 범위를 말하라”여서 둘 다 같은 증거 감사관이 된다.

대표 사례:

- `rbt-v1:character_core:isaac-newton:murder-of-roger-ackroyd-agatha-christie:MRA-Q1:r0`
  - “여러 사람이 사적인 일을 숨긴다는 사정은 원인을 찾을 단서일 수 있지만, 그것만으로 살인 책임을 연결하는 것은 아직 추정입니다.”
- `rbt-v1:character_core:marcus:murder-of-roger-ackroyd-agatha-christie:MRA-Q1:r0`
  - “누군가 비밀을 감췄다는 이유만으로 그 사람에게 살인 책임까지 묻는 것은 근거가 빠진 판단입니다.”

문자 유사도는 0.307이고, 실질적으로 둘 다 같은 사실과 같은 결론을 말한다. 뉴턴이 “시간·접근·원인의 연결”을 모델링하거나 마커스가 “해소된 혐의를 계속 적용하는 공정성”을 전면에 놓는 식의 차이는 이 질문에서 충분히 드러나지 않는다.

같은 문제가 『오만과 편견』 Q5에서도 보인다.

- `rbt-v1:character_core:isaac-newton:pride-and-prejudice-jane-austen:PNP-Q5:r0`
- `rbt-v1:character_core:marcus:pride-and-prejudice-jane-austen:PNP-Q5:r0`
- `rbt-v1:character_core:justice-tolerance-reader:pride-and-prejudice-jane-austen:PNP-Q5:r0`

세 답 모두 “첫 청혼만으로 Darcy를 고정했던 판단을 철회하고, Pemberley/Lydia 사건을 변화의 증거로 인정한다”는 동일 결론이다. 각 캐릭터의 차이는 결론 이후의 한두 단어에 머문다.

### [중간] 코어 단어가 새로운 표면 시그니처로 굳을 조짐이 있다

legacy의 직업 비유를 제거한 방향은 맞지만, 행동 원리 대신 특정 단어를 반복하면 다른 형태의 caricature가 된다.

#### 뉴턴: 모든 책을 `조건 누락` 문제로 회수

- `rbt-v1:character_core:isaac-newton:honmono-seong-hae-na:HNM-Q4:r0`
  - “문수와 신애기의 경쟁이 개인 능력만으로 생겼다는 결론에는 조건이 빠져 있습니다.”
- `rbt-v1:character_core:isaac-newton:pride-and-prejudice-jane-austen:PNP-Q4:r0`
  - “결혼을 사랑만으로 설명하면 상속, 계급 판단, 가족 평판이라는 조건이 빠집니다.”
- `rbt-v1:character_core:isaac-newton:one-hundred-years-of-solitude-gabriel-garcia-marquez:OHS-Q4:r0`
  - “가족의 반복만으로 몰락을 설명하면 중요한 외부 조건이 사라집니다.”

논리적으로는 모두 타당하지만, 다른 책을 읽고도 “빠진 조건”을 찾는 같은 장치가 먼저 보인다.

#### 무라사키 시키부: `자리·관계·마음`의 의미 과잉

- `rbt-v1:character_core:murasaki-shikibu:cosmos-carl-sagan:COS-Q1:r0`
  - “우리는 아주 작지만 서로의 삶을 읽고 기억할 자리가 있다는 점에서, 작아짐과 존엄이 함께 남네요.”

이 문장은 아름답지만 해당 행에 허용된 COS-02와 COS-10은 물질에서 의식으로 이어지는 우주 진화와 생명의 자기 인식을 말할 뿐, `서로의 삶을 읽고 기억할 자리`를 직접 지지하지 않는다. 과학 지식의 전달 방식에 대한 질문에도 두 번째 문장이 충분히 답하지 않는다. 코어가 근거보다 앞선 사례다.

#### 진: 모든 긴장을 `같은 기준·피해·책임`으로 회수

- `rbt-v1:character_core:justice-tolerance-reader:murder-of-roger-ackroyd-agatha-christie:MRA-Q4:r0`
  - “각 사람에게 같은 증명 기준을 적용해야 합니다.”
- `rbt-v1:character_core:justice-tolerance-reader:cosmos-carl-sagan:COS-Q2:r0`
  - “사람과 시대를 함께 보면 배제된 목소리와 수정할 지점도 물을 수 있어요.”

특히 COS-Q2의 허용 근거는 “현대 과학을 형성한 힘과 인물을 함께 다루며 과학을 역사적 인간 활동으로 보인다”는 내용이다. `배제된 목소리`는 가능한 후속 질문이지만 이 근거 하나가 직접 보장하지는 않는다. 정의 코어를 드러내기 위해 자료보다 한 단계 더 나간 표현이다.

이 문제는 코어 단어를 금지해서 해결하면 안 된다. 같은 단어를 쓰지 않아도 늘 같은 도덕 결론으로 돌아가면 의미상 오버핏은 남는다. 필요한 것은 **책의 구체적 충돌이 먼저이고, 코어는 무엇을 선택하고 어디서 선을 긋는지를 바꾸는 내부 원리**가 되는 것이다.

### [중간] A/B는 마커스의 caricature 개선을 보여 주지만 전체 품질 향상을 증명하지는 못한다

가장 분명한 성공은 마커스다. 법정 역할극 단어가 들어간 legacy 발화는 11/15개였지만 Character Core는 1/45개뿐이며, 그 1개도 추리소설 문맥의 자연스러운 `혐의`였다.

legacy의 고위험 사례:

- `rbt-v1:legacy_card:marcus:cosmos-carl-sagan:COS-Q4:r0`
  - “이의 있습니다, 경이는 증거능력이 아닙니다.”
- `rbt-v1:legacy_card:marcus:atomic-habits-james-clear:ATO-Q4:r0`
  - “의지가 약하다는 혐의만으로는 유죄를 선고할 수 없습니다. … 그 절차와 조건부터 심리해야 합니다.”
- `rbt-v1:legacy_card:marcus:honmono-seong-hae-na:HNM-Q1:r0`
  - “단순한 진위 판결을 기대했다면 그 판결은 첫 공판에서 흔들립니다.”

Character Core 마커스는 직업 소품 대신 주장과 책임의 연결을 말한다. 이 변화는 유지해야 한다.

다만 다른 공통 조건에서는 core와 legacy가 같은 근거와 같은 결론을 거의 그대로 공유한다.

- Character Core: `rbt-v1:character_core:isaac-newton:honmono-seong-hae-na:HNM-Q2:r0`
  - “가장 중요한 근거는 고문시설의 설계 과정을 따라가는 「구의 집」입니다. … 결과를 한 사람의 의도만으로 설명하기 어렵게 만듭니다.”
- legacy: `rbt-v1:legacy_card:isaac-newton:honmono-seong-hae-na:HNM-Q2:r0`
  - “가장 중요한 근거는 「구의 집: 갈월동 98번지」가 고문시설의 설계 과정을 따라가며 … 개인의 동기만 보아서는 설명되지 않는 결과가…”

이 쌍의 문자 유사도는 0.325다. Character Core의 효용을 평가하려면 블라인드 식별률만 볼 것이 아니라 **자연스러움, 비유 과잉, 책 고유성, 근거 밖 투사, 캐릭터 간 결론 분산**을 각각 분리해 비교해야 한다. caricature가 강한 legacy가 오히려 블라인드 식별률만 높일 수 있기 때문이다.

## 잘 작동한 부분

### 책 고유 사실은 대부분 살아 있다

『백년의 고독』에서는 가사 노동, 노동 쟁의, 군사적 진압, 집단 기억, 원고 해독을 사용하고, 『로저 애크로이드 살인 사건』에서는 딕터폰, 전화, 가방, 발자국의 증거 관계를 사용한다. 책 이름만 바꾼 범용 철학문은 아니다.

### 선택지가 열린 질문에서는 캐릭터 차이가 더 잘 드러난다

『오만과 편견』 Q2에서 선택이 갈린다.

- 뉴턴 `rbt-v1:character_core:isaac-newton:pride-and-prejudice-jane-austen:PNP-Q2:r0`: 편지와 Pemberley 관찰의 연쇄
- 마커스 `rbt-v1:character_core:marcus:pride-and-prejudice-jane-austen:PNP-Q2:r0`: 반대 설명으로서 Darcy의 편지
- 무라사키 `rbt-v1:character_core:murasaki-shikibu:pride-and-prejudice-jane-austen:PNP-Q2:r0`: Pemberley의 평판과 행동이 관계 온도를 바꾸는 과정
- 진 `rbt-v1:character_core:justice-tolerance-reader:pride-and-prejudice-jane-austen:PNP-Q2:r0`: Lydia 사건을 수습한 책임 행동

『혼모노』 Q2에서도 뉴턴은 「구의 집」, 마커스는 「우호적 감정」, 무라사키는 「스무드」를 선택한다. 이 결과는 **하나의 정답을 지정하지 않는 질문이 Character Core의 차이를 더 잘 드러낸다**는 중요한 증거다.

### 무라사키와 진은 일부 장면에서 다른 종류의 인간적 초점을 만든다

- 무라사키 `rbt-v1:character_core:murasaki-shikibu:one-hundred-years-of-solitude-gabriel-garcia-marquez:OHS-Q1:r0`은 “누구의 시간이 보이고 누구의 시간은 배경이 되는지”를 본다.
- 진 `rbt-v1:character_core:justice-tolerance-reader:one-hundred-years-of-solitude-gabriel-garcia-marquez:OHS-Q1:r0`은 “자유와 부담이 같은 사람에게 배분됐는지”를 묻는다.

같은 가사 노동 근거에서 무라사키는 관계 속 비가시성, 진은 비용의 불공정한 배분을 택한다. 이런 차이가 목표에 가장 가깝다.

## 권고안

### P0 — 다음 생성 전에 반드시 바꿀 것

1. **근거 관리를 대사에서 분리한다.**
   - 내부 출력에 `groundingDecision`, `usedEvidenceIds`, `uncertainty`를 유지한다.
   - 사용자에게 보이는 `dialogue`에는 `근거팩`, `사용자 발제`, `검증된 작품 사실`을 금지한다.
   - 자연스러운 범위 제한으로 렌더링하되, 사실성 검증은 숨은 필드로 검사한다.

2. **두 문장 고정을 없애고 발화 리듬을 평가한다.**
   - 1~3문장을 허용한다.
   - 모든 행에 질문을 강제하지는 말되, `respond_to_user`와 `directed_rebuttal`의 일정 비율은 실제 질문·확인·되묻기를 포함한다.
   - 권장 시작값은 해당 두 유형의 25~40%이며, 페르소나별 고정 할당은 피한다.

3. **책뿐 아니라 질문 형식도 holdout한다.**
   - 현재와 같은 Q1~Q5 틀을 그대로 새 책에 옮긴 결과를 일반화 성공으로 부르지 않는다.
   - holdout 일부는 자유 감상, 양자택일, 감정적 사용자 반응, 잘못은 아니지만 편향된 해석, 장면 간 충돌처럼 개발 세트에 없던 상호작용으로 구성한다.

4. **한 개의 모범 결론을 요구하는 질문 비율을 낮춘다.**
   - “맞는 부분과 과장된 부분을 구분하라”, “반대 근거를 받고 수정하라”는 구조 검증용으로만 일부 유지한다.
   - 같은 근거에서 여러 선택이 가능한 질문을 늘린다. 현재 PNP-Q2와 HNM-Q2가 좋은 모델이다.

### P1 — Character Core 생성 파이프라인 개선

5. **사고 단계와 말하기 단계를 분리한다.**
   - 1단계: 허용 근거 안에서 책 고유의 긴장과 가능한 입장 2~3개를 만든다.
   - 2단계: 캐릭터 코어가 그중 무엇을 우선하고 무엇을 포기하는지 선택한다.
   - 3단계: 선택 결과를 구어체로 렌더링한다.
   - 현재처럼 코어 단어를 바로 문장에 넣는 방식은 피한다.

6. **캐릭터 간 contrastive 검사를 추가한다.**
   - 같은 질문에서 뉴턴과 마커스가 같은 결론을 내릴 수는 있다. 그러나 뉴턴은 원인·조건·일반화 중 무엇을 바꾸고, 마커스는 책임·반증·절차 중 무엇을 바꾸는지 논증의 중심이 달라야 한다.
   - 무라사키는 관계·타이밍을 말하기 전에 실제 행동 변화가 있어야 한다.
   - 진은 불공정을 말하기 전에 누가 어떤 비용을 감당했는지 근거가 있어야 한다.
   - 차이를 만들기 위해 시그니처 단어를 억지로 삽입하면 실패로 처리한다.

7. **근거 밖 코어 투사 검사를 넣는다.**
   - “허용 근거가 이 문장의 핵심 명사를 직접 또는 합리적으로 지지하는가?”를 별도 점수로 둔다.
   - 우선 회귀 사례로 Murasaki COS-Q1의 `서로의 삶을 읽고 기억할 자리`, Justice COS-Q2의 `배제된 목소리`를 사용한다.

### P2 — 평가 지표 보완

8. 다음 점수를 블라인드 식별률과 분리해 보고한다.
   - 질문 직접 응답성
   - 근거 충실도와 근거 밖 투사
   - 책 고유 명사·사건 사용
   - 구어체 자연스러움
   - 상대 발언을 실제로 받은 정도
   - 동일 질문에서 캐릭터 간 입장·논증 중심 분산
   - 같은 캐릭터의 책 간 시그니처 단어 집중도
   - 시그니처 단어를 가린 뒤에도 남는 블라인드 식별률

9. **단발 대사가 아니라 3턴짜리 짧은 상호작용을 시험한다.**
   - 캐릭터 발화 → 사용자 반응 → 캐릭터의 양보/고수/수리.
   - 지금의 isolated 2문장 샘플은 state transition을 실제로 검증하지 못한다.

10. **A/B 판정은 다축으로 한다.**
    - legacy 마커스처럼 직업 비유가 많은 답은 “식별 가능”하지만 품질은 낮다.
    - distinctiveness와 caricature를 같은 축으로 두지 말고, 자연스러움과 grounding을 함께 통과한 식별 가능성만 성공으로 본다.

## 다음 라운드 통과 기준 제안

- 보이는 대사에서 `근거팩`, `사용자 발제` 0건.
- 문장 수가 1~3 사이에 분포하고 어느 한 길이가 80%를 넘지 않음.
- `respond_to_user`와 `directed_rebuttal`에 실제 질문 또는 확인 요청이 합계 25~40% 존재.
- 같은 질문의 네 캐릭터가 모두 같은 근거·같은 결론·같은 논증 순서를 택한 비율 25% 이하.
- 각 캐릭터의 대표 코어 단어 하나가 45개 중 40%를 넘으면 수동 검토. 단, 숫자만 맞추기 위한 동의어 치환은 실패로 간주.
- 근거 밖 핵심 주장 0건.
- legacy 대비 법정·과학자·궁정 등 직업/시대 소품 비유가 늘지 않음.
- 블라인드 식별은 시그니처 단어 마스킹 전후를 모두 보고하며, 마스킹 뒤 성능이 급락하면 구조적 개성이 아니라 표면 오버핏으로 판정.

## 최종 판단

이번 배터리는 Character Core의 **가능성**은 보여 줬다. 특히 열린 근거 선택 질문에서 책마다 다른 선택을 하면서도 캐릭터의 가치 우선순위가 드러났고, 마커스의 법정 역할극은 크게 줄었다.

하지만 현재 결과는 “9권으로 일반화가 확인됐다”기보다 “같은 다섯 가지 근거 검토 과제를 9권에서 안정적으로 수행했다”에 가깝다. 다음 개선의 핵심은 코어를 더 길게 쓰는 것이 아니라, **근거팩을 숨은 안전장치로 내리고, 질문 형식을 다양화하며, 캐릭터의 차이가 단어가 아닌 선택·양보·경계선에서 드러나게 만드는 것**이다.
