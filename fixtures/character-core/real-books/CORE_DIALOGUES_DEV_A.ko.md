# Character Core 실제 도서 개발 대사 A

이 문서는 `rbt-v2-core-dev-a` 실행의 오프라인 검토본이다. 외부 API와 앱 API를 호출하지 않았으며, 질문과 허용 근거는 개발 근거팩의 현재 문항을 그대로 따른다. 역사 인물 페르소나는 편집적 재구성이고 실제 역사에서 해당 책을 읽었다는 뜻이 아니다. 직접 인용 없이 앵커가 가리키는 요약만 사용했다.

## Cosmos — Carl Sagan

### Isaac Newton 편집적 재구성

  사용 근거: `COS-02`, `COS-07`, `COS-10`

  독자 추론: 이 독법은 첫 반응을 만드는 현상과 그 반응을 정당화하는 조건을 나누어 본다.  
  대사: 먼저 경이보다 시간척도의 차이가 눈에 들어옵니다. 물질에서 의식으로 이어지는 흐름과 태양의 유한성, 자신을 알아 가는 지구 생명을 함께 놓으면 인간은 작아지기보다 관찰 범위를 더 정확히 정해야 하는 존재로 보입니다.

- `COS-Q2` 질문: 생명, 의식, 기록, 탐사, 과학사 가운데 당신의 해석을 출발시키는 근거 하나를 고르세요. 다른 후보보다 그것을 먼저 보는 이유도 말해 주세요.

  독자 추론: 이 독법은 관찰 범위를 바꾸는 기제를 고르고 그 설명이 성립할 조건을 확인한다.  
  대사: 저는 우주 탐사를 먼저 고르겠습니다. 기록의 해독도 지식을 넓히지만, 탐사는 관찰 범위가 실제로 바뀌는 작동 조건을 보여 주므로 다른 설명이 어디까지 확인되는지 시험할 출발점이 됩니다.
