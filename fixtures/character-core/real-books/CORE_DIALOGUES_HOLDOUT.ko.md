# Character Core 실제 도서 홀드아웃 대사 v2

이 문서는 `rbt-v2-core-holdout` 실행의 오프라인 검토본이다. 외부 API와 앱 API를 호출하지 않았으며, 잠긴 질문과 허용 증거만으로 작성했다. 역사 인물 페르소나는 편집적 재구성이고 실제 역사에서 해당 책을 읽었다는 뜻이 아니다. 직접 인용 없이 제공된 요약만 사용했다.

- 행 스키마: `1`
- 생성기: `offline-core-v2-holdout-no-api`
- 기본 행: 60개
- 문장 수: 1문장 10개, 2문장 36개, 3문장 14개
- 상호작용 행의 자연스러운 질문·확인: 7/24
