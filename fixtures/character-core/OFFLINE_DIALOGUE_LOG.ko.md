## 사용 목적

- JSONL의 각 줄은 독립적인 평가 사례이며 질문, 허용 근거, 선택 가치, 대화 행동, 실제 사용 근거와 대사를 함께 보존합니다.
- 이 문서는 사람이 60개 질문과 대사를 검토하기 위한 읽기용 사본입니다.
- 이후 실제 앱 API 결과를 같은 case ID와 속성으로 기록해 참조 fixture와 비교할 수 있습니다.
- 참조 대사를 그대로 재현하는 것이 목표가 아니라, 허용 근거 준수·판단 방식 식별·경계 상태 전환·책임 이행 뒤 회복 같은 속성을 평가하는 것이 목표입니다.
