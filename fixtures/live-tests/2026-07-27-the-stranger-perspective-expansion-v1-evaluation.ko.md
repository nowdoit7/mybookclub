# 『이방인』 관점 확장형 실제 API 테스트 평가

## 결론

이번 세션은 강제 반론을 없애고 사용자의 생각을 다른 장면과 관점으로 넓히는 흐름으로 정상 완주했다. 사용자는 처음에 뫼르소의 감정 표현을 심판하는 사회의 문제에 주목했고, 대화를 마칠 때는 그 판단에 가려진 피해자의 부재와 작품 자체의 한계까지 함께 보게 되었다. 따라서 관점 확장이라는 핵심 목표는 달성했다.

다만 세 독자가 너무 일찍 `이름 없는 아랍인과 피해자의 침묵`이라는 하나의 해석으로 수렴했다. 이전의 억지 반론 문제는 줄었지만, 이번에는 서로 다른 사람이 같은 결론을 조금씩 바꾸어 반복하는 문제가 남았다. 다음 수정은 반론을 다시 넣는 것이 아니라, 각 독자가 서로 다른 장면과 관심 축을 가져오도록 하는 방향이어야 한다.

## 잘 작동한 부분

### 사용자의 생각이 실제로 확장되었다

사용자의 시작점은 `살인의 책임과 장례식 태도를 뒤섞어 판단하는 법정의 불편함`이었다. 대화가 끝날 때는 `작품의 비판적 의도와 작품이 피해자를 침묵시킨 한계를 동시에 볼 수 있다`는 생각으로 이동했다. 사용자의 기존 의견을 틀렸다고 만들지 않고 새로운 시야를 더했다.

### 질문과 발언권 반환이 자연스러웠다

데브는 사용자의 말을 요약한 뒤 다음 질문 하나만 했다.

> 카뮈가 그 불균형을 비판적으로 보여 준다고 느끼셨나요, 아니면 소설도 그 시선을 그대로 따라간다고 느끼셨나요?

질문 직후 사용자의 입력창이 열렸고, 질문한 사람과 실제 화면의 초상화도 일치했다.

### 의견 보태기 UI가 앞선 대화를 충분히 보여 주었다

사용자 입력창 위에 매디와 마커스의 전체 발화가 각각 카드로 표시되었다. 사용자는 누구의 어떤 말에 답하는지 확인할 수 있었으며, 이전처럼 반론 대상의 일부만 보이는 문제는 재현되지 않았다.

### Character Core가 찬반을 강요하지 않았다

마커스는 해변으로 다시 간 행동과 책임에 주목했지만, 다른 독자를 몰아세우거나 증거를 요구하지 않았다. 직업적 관심은 `행동과 결과를 분리해 보는 시선`으로 나타났고 반대신문 말투로 번지지 않았다.

### 모임 기록이 존재하지 않은 충돌을 크게 만들지 않았다

기록은 `서로 다르게 읽은 순간`을 햇빛과 감각에 서로 다른 무게를 둔 차이로 제한했다. 승패나 합의처럼 대화에 없던 구조를 새로 만들지 않았고, 사용자의 생각 변화도 보존했다.

## 발견된 문제

### P1. 관점이 하나의 결론으로 너무 빨리 수렴한다

전체 대화에서 다음 표현이 반복되었다.

| 표현 | 대화 구간 등장 횟수 |
|---|---:|
| 아랍인 | 11 |
| 피해자 | 14 |
| 부재 | 5 |
| 침묵 | 4 |
| 불편 | 11 |
| 부조리 | 6 |

주제가 중요하더라도 매디, 마커스, 데브가 모두 `피해자를 지운 소설의 한계`로 이동했다. 캐릭터별 차이는 문장의 표면에 남았지만 대화가 향하는 목적지는 거의 같았다.

수정 방향:

- 독자별로 서로 다른 `attention anchor`를 배정한다.
- 같은 핵심 명사를 반복하는 발화보다 아직 나오지 않은 장면을 우선한다.
- 새 발화가 앞선 발화와 같은 결론이면 감정, 관계, 서술 형식, 시대 배경, 개인 경험 중 다른 축을 추가하도록 한다.
- 차이를 만들기 위해 반대를 시키지 않는다.
- 모든 독자가 같은 결론이라면 한 명은 질문하거나 다른 장면을 가져오고, 억지로 별도 결론을 만들지 않는다.

### P1. 일부 문장이 여전히 잘 다듬어진 AI 문장처럼 들린다

검토가 필요한 표현:

- `아랍인이 끝내 이름 없이 다뤄지는 방식도 자꾸 눈에 밟혔습니다.`
- `그 대가를 분명히 보게 해 주는 말씀입니다.`
- `햇빛을 원인처럼 읽고 싶어지는 마음이 멈춰 서네요.`
- `그 시선은 ... 더 또렷하게 보여 줘요.`

문법적으로 틀리지는 않지만 실제 독서회 대화보다 에세이의 정리 문장처럼 들린다. 특히 `말씀입니다`, `마음이 멈춰 서네요`, `더 또렷하게 보여 줘요` 같은 표현은 다른 책에서도 반복되면 캐릭터보다 모델의 공통 말버릇으로 느껴질 가능성이 높다.

수정 방향:

- 한 발화에 비유적·추상적 표현을 하나 이하로 제한한다.
- 상대의 말을 평가하는 `좋은 말씀`, `분명히 보게 하는 말` 대신 바로 자신의 반응을 말한다.
- 생성 후 한국어 대화체 검사에서 `실제로 입 밖으로 말할 문장인가`를 별도로 판정한다.
- 캐릭터 공통 금지어를 늘리기보다 반복 빈도를 세션 단위로 감시한다.

### P1. 실제로는 합의에 가까운데 분위기가 `의견 차이가 선명해진 분위기`로 표시되었다

매디와 마커스의 추가 대화는 반대가 아니라 상대의 관점을 받아들이고 구체적인 행동을 보탠 흐름이었다. 그런데 UI 분위기는 잠시 `의견 차이가 선명해진 분위기`로 상승했다.

수정 방향:

- 발화 순서나 긴 대화 자체를 긴장 증가로 계산하지 않는다.
- 명시적인 불일치, 정정, 대안 해석이 있을 때만 tension을 높인다.
- 동의 후 새 장면을 보태는 발화는 energy 또는 curiosity를 높이고 tension은 유지하거나 낮춘다.

### P2. 직업을 다시 부르는 진행 문장이 불필요했다

알렉스는 `웹 게임을 기획하신다고 하셨죠`라고 사용자의 직업을 다시 언급했지만, 이후 질문과 직접적인 관련은 없었다. 잘못된 독서 성향 추론은 하지 않았으나 소개 내용을 기계적으로 재사용한 느낌이 남는다.

수정 방향:

- 직업이나 취미는 후속 질문과 실제 연결점이 있을 때만 다시 언급한다.
- 연결점이 없다면 이름과 사용자가 직접 밝힌 독서 관심사를 사용한다.

### P2. 마무리에서 다시 같은 결론을 반복한다

데브, 매디, 마커스 모두 `작품의 비판성과 피해자를 지운 한계를 함께 본다`는 결론으로 마쳤다. 마무리는 합의문을 반복하기보다 각자가 가져갈 장면, 남은 질문, 달라진 감정으로 갈라지는 편이 더 자연스럽다.

수정 방향:

- closing 역할을 `가져갈 장면`, `남은 질문`, `바뀐 생각`으로 서로 다르게 배정한다.
- 앞선 사람의 결론을 다시 요약한 마무리는 재생성한다.

### P3. 브라우저 효과음 재생 실패

대화에는 영향이 없었지만 `sfx-memberShow`가 브라우저 자동 재생 제한으로 한 번 실패했다. API 오류는 아니며 기능상 차단 요소도 아니었다.

수정 방향:

- 사용자 상호작용 전 자동 효과음 재생을 시도하지 않는다.
- 자동 재생 실패는 API 진단 실패와 시각적으로 분리한다.

## 사용자 2차 언어 리뷰

사용자는 이전 버전보다 좋아졌지만 감정어의 종류와 관점의 다양성에는
아직 큰 수정이 필요하다고 판정했다.

### 감정이 비평어 뒤로 숨는다

`불편했다`가 장례식, 재판, 인물의 행동처럼 성격이 다른 반응에 반복
사용되었다. 캐릭터가 직접 감정을 갖지 못하게 막은 결과라기보다,
프롬프트가 `felt response`를 요구하면서도 구체적인 감정의 종류를
구분하지 않아 모델이 안전한 평가어로 수렴한 결과에 가깝다.

사용자 교정 예시:

| 생성 표현 | 이 문맥에서 더 자연스러운 방향 |
|---|---|
| 아랍인이 끝내 이름 없이 다뤄지는 방식도 자꾸 눈에 밟혔습니다. | 마음이 쓰였습니다. / 신경이 쓰였습니다. |
| 장면이 저는 불편하게 기억에 남아요. | 그 장면이 기억에 남아요. |
| 장례 직후라는 시간 때문에 저도 먼저 불편했지만 | 장례 직후라 저도 좀 이해하기 어려웠지만 |
| 그 대가를 분명히 보게 해 주는 말씀입니다. | 그 이야기를 들으니 누가 대가를 치르는지 더 분명해지네요. |
| 마음이 멈춰 서네요. | 그 부분은 중요하게 봐야겠네요. |
| 더 또렷하게 보여 줘요. | 작가의 의도가 더 분명히 드러난다고 생각해요. |

이 표는 전역 치환표가 아니다. `마음이 쓰였다`, `속상했다`,
`이해하기 어려웠다`, `답답했다`, `화가 났다`, `궁금했다` 가운데
장면과 캐릭터에 맞는 반응을 고르기 위한 문맥 예시다.

### 사람처럼 들린 사용자 발화

다음 문장은 자동 테스트에서 플레이어 입력으로 사용했지만 사용자는
사람이 말한 글처럼 자연스럽다고 판정했다.

> 재판에서 살인의 구체적인 경위보다 어머니 장례식에서 울지 않았고
> 커피를 마셨다는 일을 되풀이해 묻는 장면이 가장 기억에 남았습니다.
> 피해자의 삶은 거의 보이지 않는데 뫼르소가 애도를 제대로 연기했는지는
> 크게 다뤄져서, 법정이 무엇을 심판하는지 혼란스러웠습니다.

이 문장의 특징은 추상적인 감상어보다 실제 장면, 비교 대상, 마지막에
든 감정을 순서대로 말한다는 점이다. 캐릭터 발화도 이 구조를 참고하되
모두 같은 문장 공식으로 만들지는 않는다.

### 웹의 대표 해석을 모든 캐릭터가 따라간다

사용자는 `이름 없는 아랍인`에 관한 비평이 웹과 위키 등에 많이
존재하기 때문에 도서 검증과 독서 메모가 그 해석을 과대 대표했을
가능성을 지적했다. 코드 점검 결과 세 캐릭터는 동일한 웹 기반 요약과
동일한 후보 질문을 받은 상태에서 서로의 메모를 모른 채 독립적으로
독서 메모를 만든다. 이후 선택 로직은 한국어 문장을 공백 단위로만
비교하므로 의미상 같은 관점의 중복을 충분히 발견하지 못한다.

따라서 해결책은 유명한 해석을 금지하는 것이 아니다. 한 독자가 이미
그 해석을 중심으로 말했다면 다른 독자는 같은 결론을 반복하지 않고,
아직 나오지 않은 장면·인물·관계·서술 형식·개인적 질문 중 하나를
가져오게 해야 한다.

## 다음 수정 우선순위

1. 독서 메모에 구체 감정과 감정의 대상을 분리해 기록한다.
2. 관점 중복 방지용 `attention anchor + contribution type` 계획을 추가한다.
